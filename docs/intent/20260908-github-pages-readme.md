# README points at the published app

Date: 2026-09-08

## What

Rewrite the README around a link to the app, now live on GitHub Pages.

## Why

The README said two lines and linked nothing. A visitor could not tell what
Mortise does, or that a working app was one click away.

## How

Say what the app is, how to run it locally, and where it is hosted. Keep it
short — `AGENTS.md` carries the conventions.

Pages serves the branch directly. No Actions workflow: there is no build step,
so it would add a moving part and buy nothing.
