# Mortise

Rough cost estimates for carpenters. Lean, static, offline.

**[Open the app](https://oberprah.github.io/mortise/)**

A carpenter adds furniture pieces, picks materials and add-ons, and sees a
live total. The result goes to the customer as a PDF. Projects are saved as
JSON files.

It is a proof of concept, not yet in use.

## Run it locally

Open `index.html` in a browser. No build step, no server, no backend. The
whole app is that one file, and it works offline.

## Hosting

GitHub Pages serves `index.html` from `main`, root folder. A push to `main`
publishes it.
